**147) Edit Distance**
https://leetcode.com/problems/edit-distance/description/
**Условие:**
Даны две строки **word1** и **word2**, необходимо вернуть минимальное количество операций, которые нужно совершить, чтобы превратить строку **word1** в строку **word2**.
Есть следующие операции: добавить символ, удалить символ, заменить символ
**Идея:**
Представить это в виде рекурсии и развернуть
**Реализация:**
    Снова создадим матрицу **dp**, в которой **dp**[**i**][**j**] будет означать минимальное количество операций, чтобы превратить **word1**[:**i**] в **word2**[**j**].
    Крайними случая будут те, где **word1** пустая строка или **word2** пустая строка. В этих случаях **dp**[**i**][**0**] = **i** или **dp**[**0**][**j**] = **j**. (Нужно будет удалить **i** букв или вставить **j** букв).
    В динамическом случае, есть хороший случай, когда **word1**[**i** - **1**] == **word**[**j** - **1**], то есть нам ничего делать не нужно. И есть плохой случай, когда необходимо удалить, вставить или заменить символ. В этом случае **dp**[**i**][**j**] = **min**(**dp**[**i** - **1**][**j**], **dp**[**i**][**j** - **1**], **dp**[**i** - **1**][**j** - **1**]) + **1**.
    **1**) **dp**[**i** - **1**][**j**] - удаление символа из **word1** (длина уменьшается на **1**, то есть **i**)
    **2**) **dp**[**i**][**j** - **1**] - вставка символа из **word2** (упрощает нам задачу на **1** символ, то есть **j**)
    **3**) **dp**[**i** - **1**][**j** - **1**] - замена символа из **word1** на символ из **word2** (Можно заметить, что это комбинация удаления и последующей вставки).
    В конце ответ будет в последней ячейке **dp**.

**Оценка:**
    По времени алгоритм займет **O**(**N** * **M**), где **N** - **len**(**word1**), а **M** - **len**(**word2**).
    По памяти будет то же самое **O**(**N** * **M**).
