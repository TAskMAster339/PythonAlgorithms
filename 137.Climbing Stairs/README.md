<h1><a href='https://leetcode.com/problems/climbing-stairs/description/'><strong>137) Climbing Stairs</strong></a></h1>
</div>

## **Условие:**

Представьте, что вы поднимаетесь по лестнице, в ней всего **n** ступеней. Каждый раз вы либо поднимаетесь на **1** ступень, либо прыгаете сразу на **2** ступеньки. Сколькими способами вы сможете подняться на **n** ступеней

## **Идея:**

Простейшая задача на динамическое программирование (ДП)

## **Реализация:**

ДП - всего-навсего оптимизация рекурсии, поэтому в начале нужно решить задачу рекурсии, а потом оптимизировать рекурсию. ДП используется, когда необходимо уменьшить глубину рекурсии или рекурсия слишком много раз повторяет вычисления (Например, расчет чисел Фибоначчи рекурсивно будет очень неэффективен, так как для каждого числа мы будем пересчитывать все предыдущие числа).

В начале крайний случай это **n** <= **3**, тогда ответ будут **n**. В рекуррентном случае, то есть динамическом, мы будем итеративно заполнять массив **dp**, где каждое следующие число будет равно сумме двух предыдущих. Понять это можно так: чтобы попасть на **i**-тую ступеньку, нам нужно быть либо на (**i**-**1**)-той ступеньке и сделать **1** шаг, либо на (**i**-**2**)-той ступеньке и прыгнуть на **2**. И так далее думаем до крайних ступенек.



## **Оценка:**

По времени мы затратим **O**(**N**), так как необходимо будет досчитать все варианты для **N**-ой ступеньки. По памяти выйдет **O**(**N**), так как мы будем запоминать все результаты. Память можно оптимизировать до **O**(**1**), если заметить, что наши числа образует последовательность подобную числам Фибоначчи, для вычисления которых достаточно **2**-ух переменных.

## Код:
```python
class Solution:
    def climbStairs(self, n: int) -> int:
        if n <= 3:
            return n

        dp = [0] * (n + 1)
        dp[1], dp[2] = 1, 2

        for i in range(3, n + 1):
            dp[i] = dp[i - 1] + dp[i - 2]

        return dp[n]


if __name__ == "__main__":
    f = Solution().climbStairs
    print(f(2))  # 2
    print(f(3))  # 3

```
