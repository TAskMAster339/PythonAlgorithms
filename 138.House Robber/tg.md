**138) House Robber**
https://leetcode.com/problems/house-robber/description/
**Условие:**
Вы снова представляете себя профессиональным вором лошадей на улице. Каждая лошадь стоит определённое количество денег, единственное, что может остановить вас - это сигнализация, которая автоматически активируется, если две рядом стоящие лошади будут украдены.
Дан массив целых чисел **nums**, который представляет количество денег, которое можно выудить за каждую лошадь. Необходимо вернуть максимальное количество денег, которое можно заработать на краже лошадей, при этом вас не должны поймать
**Идея:**
Упростить задачу до массива из **1**, **2** элементов и затем динамически обобщить для случая из **n** элементов
**Реализация:**
    Если длина массива меньше или равна **2**, то мы просто воруем самую дорогую лошадь. Это наш крайний случай.
    Если есть еще варианты, то мы вынуждены создать массив **dp**, в котором целое число **dp**[**i**] - будет означать максимальное количество денег, которое мы можем заработать воруя лошадей **nums**[:**i** + **1**]. Для начало нужно заполнить крайнии случаи для **i** = **1**, **2**. Затем в цикле останется динамически вычислять **dp**[**i**], которое будет равно **max**[**dp**[**i** - **1**], **dp**[**i** - **2**] + **nums**[**i**]] (То есть либо предыдущему максимальному числу, либо пред-предыдущему максимуму + стоимость текущей лошади, так как её кража не затригирит сигнализацию).
    В конце остается вернуть **dp**[-**1**].

**Оценка:**
    Сложность по времени будет равна **O**(**N**), так как в наихудшем случае мы должны будем просчитать все схему кражи лошадей.
    По памяти мы затратим **O**(**N**), расходы на массив **dp**, при этом тоже можно оптимизировать до двух-трёх переменных.
