</div>

## **Условие:**

Даны строки **s1**, **s2** и **s3**, необходимо выяснить может ли строка **s3** быть сформированной пересечением строки **s1** и **s2**.

Пересечением двух строк **s1** и **s2** называется строка **s3**, которая является конкатенацией подстрок **s1** и **s2**.

То есть пересечение двух строк - такая строка, которая состоит из букв этих строк, но каждая буква не меняет своё положение относительно её исходного положения в её исходной строке

## **Идея:**

Смотри рисунок

## **Реализация:**

Создадим двумерный массив **dp**, где **dp**[**i**][**j**] будет означать можно ли собрать строку **s3**[:**i**+**j**] **c** помощью строк **s1**[:**i**] и **s2**[:**j**]. Крайний случай это **dp**[**0**][**0**] = **True**.

В динамическом случае нам необходимо проверить три случая: два вырожденных, когда строка **s3** формируется пересечением **s1** **c** пустой строкой или **s2** с пустой строкой.

И нормальный случай. В обоих случаях мы будем заполнять нашу динамическую матрицу **dp** по следующему правилу: **dp**[**i**][**j**] = (**dp**[**i**-**1**][**j**] **and** **s1**[**i**-**1**] == **s3**[**i**+**j**-**1**]) **or** (**dp**[**i**][**j**-**1**] **and** **s2**[**j**-**1**] == **s3**[**i**+**j**-**1**]).

То есть мы, как бы динамически проверяем возможность собрать строку **s3**[:**i**+**j**] из символов строк **s1**[:**i**] и **s2**[:**j**]. Условие с **And** позволяет проверять, что мы не нарушаем порядок следование букв в исходных строках.

В конце получим ответ в **dp**[**m**][**n**].



## **Оценка:**

Сложность по времени будет **O**(**N** * **M**), где **N**, **M** - длины строк **s1**, **s2**.

Сложность по памяти будет **O**(**N** * **M**), при этом если заметить некоторую закономерность. то можно оптимизировать до **O**(**max**(**N**, **M**)).

## Код:
```python
class Solution:
    def isInterleave(self, s1: str, s2: str, s3: str) -> bool:
        m, n = len(s1), len(s2)
        if m + n != len(s3):
            return False

        dp = [[False] * (n + 1) for _ in range(m + 1)]
        dp[0][0] = True

        for i in range(1, m + 1):
            dp[i][0] = dp[i - 1][0] and s1[i - 1] == s3[i - 1]

        for j in range(1, n + 1):
            dp[0][j] = dp[0][j - 1] and s2[j - 1] == s3[j - 1]

        for i in range(1, m + 1):
            for j in range(1, n + 1):
                dp[i][j] = (dp[i - 1][j] and s1[i - 1] == s3[i + j - 1]) or (
                    dp[i][j - 1] and s2[j - 1] == s3[i + j - 1]
                )

        return dp[m][n]


if __name__ == "__main__":
    f = Solution().isInterleave
    print(f("aabcc", "dbbca", "aadbbcbcac"))  # True
    print(f("aabcc", "dbbca", "aadbbbaccc"))  # False
    print(f("", "", ""))  # True

```
