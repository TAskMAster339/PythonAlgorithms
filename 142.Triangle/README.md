<h1><a href='https://leetcode.com/problems/triangle/description/'><strong>142) Triangle</strong></a></h1>

## **Условие:**

Дан двумерный массив **triangle**, нужно вернуть наименьший путь от верха треугольника до его низа.

На каждой ступени можно спускаться либо влево, или вправо, то есть, если вы находитесь на индексе **i**, то вы можете спуститься только на **i** или на **i** + **1** индексы на следующем уровне

## **Идея:**

Динамически рассчитать матрицу **dp**, где **dp**[**i**][**j**] будет наименьшей путь от **triangle**[**0**][**0**] до **dp**[**i**][**j**], но можно уложиться в массив **dp**

## **Реализация:**

Создадим массив **dp** с нулями длинной **len**(**triangle**) + **1**. И затем представим треугольник следующим образом:

**2** - первый уровень

**3** **4** - второй уровень

**6** **5** **7** - третий уровень

**4** **1** **8** **3** - четвертый уровень

**0** **0** **0** **0** **0** - **dp** (мнимый пятый уровень)

Будем идти снизу вверх, заполняя **dp** по следующий формуле **dp**[**i**] = **triangle**[**j**][**i**] + **min**(**dp**[**i**], **dp**[**i** + **1**]), где **j** - номер уровня треугольника, которые вычисляется снизу вверх. **i** - индекс элемента уровня. (Смысл формулы следующий: **triangle**[**j**][**i**] - длина пути, которая добавиться, если мы пойдем в **i**-тую ячейку, **min**(**dp**[**i**], **dp**[**i** + **1**]) - мы идем туда оттуда, где путь уже меньше. (**dp**[**i**] и **dp**[**i** + **1**] - единственные возможные наши ходы по условию))

То есть мы будем вычислять вот такие треугольники:

**4**    **1**    **8**

**0** **0**  **0** **0**  **0** **0**  и т.д

Получим **dp** = [**4**, **1**, **8**, **3**, **0**]. Мы скопировали последний уровень треугольника в **dp**. Если мы будем повторять дальше, то мы будем аккумулировать минимальный путь снизу треугольника к его вершине.

**6**    **5**    **7**

**4** **1**  **1** **8**  **8** **3**

[**7**, **6**, **10**, **3**, **0**]

**3**    **4**

**7** **6**  **6** **10**

[**9**, **10**, **10**, **3**, **0**]

**2**

**9** **10**

[**11**, **10**, **10**, **3**, **0**]

В **dp**[**0**] получаем ответ.



## **Оценка:**

По времени мы затратим **O**(**N**), где **N** - количество элементов в треугольнике.

По памяти сложность будет **O**(**K**), где **K** - **len**(**triangle**[-**1**]). Еще можно заметить, что можно этот алгоритм реализовать **in**-**place** (Пусть последний уровень треугольника будет нашим **dp**), то мы получим **O**(**1**).

## Код:
```python
class Solution:
    def minimumTotal(self, triangle: list[list[int]]) -> int:
        dp = [0] * (len(triangle) + 1)

        for row in triangle[::-1]:
            for i, n in enumerate(row):
                dp[i] = n + min(dp[i], dp[i + 1])

        return dp[0]


if __name__ == "__main__":
    f = Solution().minimumTotal
    print(f([[2], [3, 4], [6, 5, 7], [4, 1, 8, 3]]))  # 11
    print(f([[-10]]))  # -10
    print(f([[-1], [2, 3], [1, -1, -3]]))  # -1

```
